SPI：通常三根公共信号线 + 每个设备一根片选线，通过“CS”选择设备。
SPI 则通常使用 SCK、MISO、MOSI 和 SS/CS 四类信号，多个从设备可以通过不同 CS 线进行选择。
SPI 通常有四根线：分别是：
SCK时钟。MOSI主设备 → 从设备。MISO从设备 → 主设备。CS片选。
用来告诉某个从设备：
“现在轮到你跟我通信了。”
ST 的 SPI 入门资料也是以 SCK、MISO、MOSI、SS/CS 作为典型四线 SPI 接口。
SPI 为什么有两个 CS？
因为你这里实际上把：BMI088 加速度计 BMI088 陀螺仪当作两个 SPI 从设备来选择。
SPI 为什么不需要像 I2C 一样的设备地址？
因为 SPI 用：CS / SS 片选来选择设备。
哪个 CS 被拉低，哪个设备工作。
