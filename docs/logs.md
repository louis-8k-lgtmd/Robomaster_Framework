# 项目修改日志

按代码修改发生顺序简洁记录；已撤销或调整的历史实现会在对应条目中注明。

## 1. USART1 接收初次修改
- 在 `bsp/src/bsp_usart.cpp` 增加 USART1 Receive-to-Idle DMA 启动及接收回调。
- 此次修改后来被用户撤销，不作为当前代码状态。

## 2. USART1/USART6 DMA 初始化
- 为两路 UART 增加独立静态接收缓冲区。
- 调用 CubeMX 初始化函数，启动 Receive-to-Idle DMA，并关闭 DMA 半传输中断。
- 增加接收事件回调，在一帧接收后重新启动普通模式 DMA。
- 后续用户对 USART 代码进行了调整和扩展。

## 3. PWM 封装实现
- 在 `bsp/src/bsp_pwm.cpp` 实现 TIM1 PWM 初始化、通道启停、周期换算和占空比设置。
- 周期计算考虑 APB 定时器时钟、预分频值及 ARR 位宽；对无效参数进行保护。
- 后续用户继续调整了该文件，当前实现以源文件为准。

## 4. USART 收发接口修正
- 修正 DMA 接收长度和 HAL 状态码检查，统一阻塞模式枚举名称。
- 在 `bsp/src/bsp_usart.cpp` 实现阻塞、IT、DMA 发送/接收模式分发，并添加 Receive-to-Idle 回调重启。
- 在 `bsp/include/bsp_usart.hpp` 将 `USART_Receive` 声明改为与四参数定义一致。
- 后续用户继续加入 ThreadX 桥接和队列处理代码。

## 5. 根目录 CMake 入口修复
- 将根目录 `CMakeLists.txt` 改为委托构建 `board` 子工程。
- 将根目录 `CMakePresets.json` 的 ARM 工具链路径改为 `board/cmake/gcc-arm-none-eabi.cmake`。
- 使用 CMake Tools 构建成功，生成 `board/board.elf`。该 target 当时只包含 `board` 中的 CubeMX、HAL 和 ThreadX 源码，未包含 `bsp/` 等框架目录。

## 6. CAN 收发与反馈路由
- 配置并启动 CAN1/CAN2，启用 FIFO0 接收通知，提供标准帧发送接口和参数/状态检查。
- 将 DJI 电机反馈帧按总线和 ID 分发给电机管理器。

## 7. PID 与数值函数
- 实现位置式、增量式 PID，支持误差历史、积分限幅、输出限幅、状态清零及在线调参。
- 实现对称数值限幅函数，并将相关源文件纳入工程构建。

## 8. BMI088 驱动
- 实现 SPI 寄存器读写、双芯片片选、软复位、ID 校验和量程/采样配置。
- 实现加速度、角速度、温度解析及单位换算；加速度读取丢弃首个无效字节。
- 增加数据有效性和通信错误状态；未配置板级加热器，温控保持不可用。

## 9. 电机管理与 M2006 控制
- 实现电机注册、CAN 控制帧分组打包、反馈解析、编码器回绕及位置累计。
- 实现 M2006 速度环、位置-速度串级控制、电流限幅和反馈在线检查。

## 10. LED 与应用任务
- 实现低电平有效的 RGB LED 控制和供 C 代码使用的接口。
- 新增 BMI088 任务接口与单电机控制任务；位置目标须在首帧编码器反馈后设置。
- 控制任务上电默认保持 RELAX，不自动驱动电机。

## 11. ThreadX 线程与心跳监控
- 创建 UART、IMU、电机控制和 Alive Monitor 线程及所需信号量。
- UART DMA 收帧复制到环形队列，由线程上下文处理；IMU 线程发布最新样本。
- 区分线程存活心跳与功能操作成功状态，并映射到 RGB 灯效。

## 12. 通信和线程状态修正
- 将 UART DMA 启动消息改为通过 BSP 发送接口；发送/初始化状态用于上层判定。
- 删除重复控制任务初始化；保留 PWM 通道关闭状态，CRC 未被调用且未纳入构建。

## 13. 项目代码注释
- 为项目自有 BSP、PID/数值、BMI088、电机、LED、任务和 ThreadX 应用代码补充中文注释。
- 进一步说明 CAN/UART/PWM/CRC 数据流、控制公式、单位、边界条件和线程状态。
- 跳过 HAL、CMSIS、ThreadX 等供应商代码；空的 `threads` 文件不添加注释。
